AI provider settings

Install Ollama, then run ollama pull qwen2.5:3b. Your prompts are sent to the Ollama service on the URL above.

Use openrouter/free to route only to currently available free models, or choose a model explicitly marked free in OpenRouter's catalog. Free models have changing rate limits and availability; do not configure paid fallbacks.

Get an API key

Without a browser key, OpenRouter requests use this function. Set OPENROUTER_API_KEY on your own Netlify site; never commit a key to source.

Data & privacy

Projects are saved in this browser's local storage. Clearing browser data may remove them. Media selection does not upload files.

Local image generation

Optional AUTOMATIC1111 / Forge API. Install a model and enable the local API; setup instructions are in the README. No image API key is used.

What is connected?

Local tools Project workflow, microphone voice recording, image upload, local Stable Diffusion image API, image motion clips, browser video rendering, audio mixing and downloads.

Optional AI Local Ollama text models and local Stable Diffusion. OpenRouter free models require a user key; limits can change.

Not connected Generative AI video models, live competitor scraping, direct YouTube upload. Image-to-video currently uses local pan/zoom animation, not generative video.
